C2ProcLogistic

Python replication of SAS PROC LOGISTIC for binary outcomes

C2ProcLogistic provides two classes — C2Logistic and C2LogisticE — that replicate the output, defaults, and behaviour of SAS PROC LOGISTIC for binary (0/1 or two-level) response variables. The library handles model fitting, result tables, goodness-of-fit statistics, and four Plotly-based diagnostic plots, all in a single function call.

Both classes accept identical arguments. The only difference is the coding method applied to categorical predictors: C2Logistic uses reference (dummy) coding (PARAM=REF in SAS), while C2LogisticE uses effect coding (PARAM=EFFECT in SAS). See Coding Methods for a full comparison.

SAS culture defaults: Key defaults are aligned with SAS PROC LOGISTIC — ref='LAST' (last sorted level is reference, matching SAS ORDER=FORMATTED with PARAM=REF), rsquare=False, lackfit=False, maxiter=25, ci=0.95. Opting into rsquare or lackfit mirrors explicitly requesting those options in SAS.

Coding Methods

When a predictor is categorical (non-numeric), the library must convert its levels into numeric columns before fitting the logistic model. The two classes implement different conventions for this conversion, matching the two most common SAS PARAM= options.

PARAM=REF — Reference (Dummy) Coding  →  C2Logistic

SAS equivalent: MODEL outcome = predictors / PARAM=REF;

For a categorical variable with levels A, B, C where C is the reference (default: last sorted), two binary columns are created: one for A (1 if A, else 0) and one for B (1 if B, else 0). Level C gets all zeros in both columns — it is the reference and has no explicit column.

What the coefficient means: Each coefficient is the log-odds of the event for that level relative to the reference level, holding other predictors constant. The odds ratio for level A compares A vs C directly.

The reference level is always excluded from the parameter table. You will not see an estimate row for the reference level — only for the non-reference levels.

PARAM=EFFECT — Effect Coding  →  C2LogisticE

SAS equivalent: MODEL outcome = predictors / PARAM=EFFECT;

Same column structure as reference coding, except the reference level receives −1 in every dummy column instead of 0. All other levels still receive 0 or 1 as normal.

What the coefficient means: Each coefficient represents the deviation of that level's log-odds from the unweighted grand mean log-odds across all levels. The reference level's deviation is the negative sum of all other level coefficients (it is implied, not printed directly).

Use effect coding when: you want to interpret effects relative to an overall average rather than relative to a specific reference category — common in designed experiments and analysis of variance-style interpretations.

Side-by-side comparison

Property C2Logistic (PARAM=REF) C2LogisticE (PARAM=EFFECT)
SAS option PARAM=REF PARAM=EFFECT

C2Logistic

class
C2Logistic(data, outcome, predictors, *, event=None, ref='LAST', by=None, maxiter=25, ci=0.95, rsquare=False, lackfit=False, decimals=4, output='html', filepath=None, forest_plot=False, roc_plot=False, influence=False, effect_plot=False, plot_options=None)

Fits a binary logistic regression model using reference (dummy) coding for categorical predictors, matching SAS PROC LOGISTIC with PARAM=REF. Model fitting uses Fisher scoring (iteratively reweighted least squares). On construction the model runs immediately, prints a console summary, builds any requested plots, and saves the output file.

Parameters

data pd.DataFrame required

The input dataset as a pandas DataFrame. All outcome and predictor columns must be present. Rows with missing values in the outcome or any predictor are silently dropped before fitting.

outcome str required

Name of the response (dependent) variable column. Must be binary: either numeric 0/1, or a two-level string/categorical column (e.g. 'yes'/'no', 'event'/'nonevent').

When the column is numeric 0/1, the model is fitted as-is (models P(y=1)). When the column is non-numeric, the higher alphabetically-sorted level is treated as the event by default — override with the event argument.

predictors list of str required

List of predictor (independent variable) column names. Example: ['age', 'job_C', 'balance'].

Numeric columns are treated as continuous and enter the model unchanged. Non-numeric (object/categorical) columns are automatically encoded using the coding method of the class (C2Logistic → reference coding).

Column names that have already been dummy-encoded externally (e.g. job_C where _C signals categorical) should be listed here as regular names — the class inspects the column's dtype, not its name.

event str default: None

Specifies which value of outcome is the event (the outcome being modelled as P=1). Only needed when the outcome column is non-numeric.

If None, the higher alphabetically-sorted level is used as the event — consistent with SAS default event ordering. Pass the exact value as a string, e.g. event='yes' or event='1'.

Raises ValueError if the supplied value is not found in the outcome column.

ref str or dict default: 'LAST'

Controls the reference level for categorical predictors. Three forms are accepted:

  • 'LAST' — last sorted level becomes the reference. This is the default, matching SAS PARAM=REF with ORDER=FORMATTED.
  • 'FIRST' — first sorted level is the reference (patsy's natural default).
  • {'varname': 'level'} — a dict specifying the reference level per variable. Variables not mentioned in the dict fall back to 'FIRST'.

This argument has no effect on numeric (continuous) predictors.

See the ref argument section for detailed examples.

by str default: None

Name of a grouping column. When supplied, the model is fitted separately for each unique value of this column (equivalent to a SAS BY statement). Results for each group are printed in sequence and all included in a single output file.

The .dataset property will contain a label column identifying the group (e.g. "education = primary").

maxiter int default: 25

Maximum number of Fisher scoring (IWLS) iterations allowed for convergence. Matches the SAS MAXITER= option default of 25. Convergence criterion is gradient < 1e-8 (matching SAS GCONV=1e-8). If the model does not converge within this limit, a warning is issued and results are reported at the final iteration.

ci float default: 0.95

Confidence interval level as a proportion between 0 and 1. Default 0.95 produces 95% Wald confidence intervals for log-odds and odds ratios. Change to 0.90 for 90% CIs, 0.99 for 99% CIs, etc.

Raises ValueError if not strictly between 0 and 1.

rsquare bool default: False

When True, computes and prints two R-Square metrics based on log-likelihoods:

  • R-Square — Cox & Snell pseudo R²
  • Max-rescaled R-Square — Nagelkerke R² (rescaled so maximum = 1)

False by default, matching the SAS default where these are not printed unless explicitly requested with the /RSQUARE option.

See Optional Statistics — rsquare for details.

lackfit bool default: False

When True, computes and prints the Hosmer-Lemeshow goodness-of-fit test, including the full partition table (observed vs expected counts by decile group) and the chi-square test statistic with p-value.

False by default, matching the SAS default where this is only produced when /LACKFIT is specified on the MODEL statement.

See Optional Statistics — lackfit for details.

decimals int default: 4

Number of decimal places used in all printed tables (console and HTML output). Applies to parameter estimates, standard errors, odds ratios, confidence intervals, and p-values. Does not affect the .dataset DataFrame, which always stores 6 decimal places.

output str default: 'html'

Format of the saved output file. Accepted values:

  • 'html' — styled HTML report containing all result tables and embedded plots
  • 'csv' — flat CSV of the .dataset DataFrame
  • 'excel' — Excel .xlsx file of the .dataset DataFrame

Raises ValueError for any other value.

filepath str default: None

Path (including filename) for the output file. If None, the file is saved in the current working directory as output.html, output.csv, or output.xlsx depending on the output argument. A directory path may be included, e.g. 'results/run1.html'.

forest_plot bool default: False

When True, generates a Forest Plot showing odds ratios and their Wald confidence intervals for all non-intercept parameters. The plot is embedded in the HTML output and accessible as result.forest_plot. See Plots — Forest Plot.

roc_plot bool default: False

When True, generates an ROC (Receiver Operating Characteristic) curve showing sensitivity vs 1-specificity across 200 threshold values, with the AUC displayed in the legend. Accessible as result.roc_plot. See Plots — ROC Curve.

influence bool default: False

When True, generates two 2×2 panels of influence diagnostic plots:

  • Panel 1: Pearson residual, Deviance residual, Leverage, CI Displacement C
  • Panel 2: CI Displacement Cbar, Chi-Square deletion difference, Deviance deletion difference

Accessible as result.influence_plot which returns a tuple (panel1, panel2). See Plots — Influence Plots.

effect_plot bool default: False

When True, generates an Effect Plot (predicted probability curve) showing modelled probability of the event against the first continuous predictor in the model, with separate lines for each level of the first categorical predictor (if present). All other continuous predictors are held at their mean; other categoricals at their mode. Accessible as result.effect_plot. See Plots — Effect Plot.

plot_options dict default: None

Optional dict of Plotly display overrides applied to all plots generated in the call. Accepted keys:

  • 'width' — figure width in pixels
  • 'height' — figure height in pixels
  • 'title' — title override (applied to all plots — use helper functions for per-plot titles)

Example: plot_options={'width': 900, 'height': 500}. For more granular per-plot control, use the plot helper functions after the call.

Attributes / Returns

The constructor runs the model immediately. The result object exposes the following attributes:

.dataset pd.DataFrame

Results as a flat pandas DataFrame. One row per parameter per BY-group. Columns include: label, parameter, log_or, se, wald_chisq, p_value, confidence interval bounds for log-OR and OR (named dynamically with the CI level, e.g. or_lower_95), odds_ratio, n_obs, converged, iterations, separation, warning_issued. All numeric columns stored to 6 decimal places.

.forest_plot Plotly Figure

Forest Plot figure. Only available when forest_plot=True was passed. Raises RuntimeError if accessed without enabling. Use fig.show() to display interactively or fig.write_html('file.html') to save.

.roc_plot Plotly Figure

ROC Curve figure. Only available when roc_plot=True was passed. Raises RuntimeError if accessed without enabling.

.influence_plot tuple of Plotly Figures — (panel1, panel2)

Influence diagnostic panels. Only available when influence=True was passed. Returns a tuple of two Plotly figures. Raises RuntimeError if accessed without enabling.

.effect_plot Plotly Figure

Predicted probability curve. Only available when effect_plot=True was passed. Raises RuntimeError if accessed without enabling.

)

C2LogisticE

class
Identical interface to C2Logistic. Every argument name, type, default value, and behaviour is the same. The only difference is the internal encoding of categorical predictors: C2LogisticE uses effect coding (reference level = −1) instead of dummy coding (reference level = 0/omitted). See Coding Methods.
C2LogisticE(data, outcome, predictors, *, event=None, ref='LAST', by=None, maxiter=25, ci=0.95, rsquare=False, lackfit=False, decimals=4, output='html', filepath=None, forest_plot=False, roc_plot=False, influence=False, effect_plot=False, plot_options=None)

Fits a binary logistic regression model using effect coding for categorical predictors, matching SAS PROC LOGISTIC with PARAM=EFFECT.

Parameters

All parameters are identical to C2Logistic. The table below highlights only what changes in behaviour due to effect coding:

ParameterDefaultBehaviour specific to C2LogisticE
ref 'LAST' Still controls which level is the reference. In effect coding, that level receives −1 in all dummy columns. The same three forms are accepted: 'LAST', 'FIRST', dict.
All others same Identical behaviour to C2Logistic in all respects.

The console header will print [PARAM=EFFECT] to distinguish output from C2Logistic.

Examples

from C2ProcLogistic import C2LogisticE

# Minimal — effect coding, all other defaults same as C2Logistic
result = C2LogisticE(
    data       = df,
    outcome    = 'purchased',
    predictors = ['age', 'job_C', 'balance']
)

# With event and plots
result = C2LogisticE(
    data        = df,
    outcome     = 'purchased',
    event       = 'yes',
    predictors  = ['age', 'balance_T', 'job_C'],
    ref         = 'LAST',
    ci          = 0.95,
    rsquare     = True,
    lackfit     = True,
    forest_plot = True,
    roc_plot    = True,
)

df_out = result.dataset

The ref Argument

The ref argument controls the reference level for categorical (non-numeric) predictors. It applies in both C2Logistic and C2LogisticE. Three forms are accepted.

SAS parallel: ref='LAST' matches SAS PARAM=REF ORDER=FORMATTED where the last formatted value (alphabetically last) is the reference. ref='FIRST' matches PARAM=REF ORDER=DATA or patsy's natural default.

'LAST' — default

The last alphabetically-sorted unique level of each categorical predictor becomes the reference. This is the default and mirrors SAS default behaviour. For a predictor with levels ['admin', 'blue-collar', 'student'], the reference would be 'student' (last alphabetically). You will see estimates for admin and blue-collar but not student. 

result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C'],
    ref        = 'LAST'   # default — can be omitted
)

'FIRST'

The first alphabetically-sorted unique level becomes the reference. For ['admin', 'blue-collar', 'student'], the reference would be 'admin'. This is patsy's natural default for C() terms. 

result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C'],
    ref        = 'FIRST'
)

dict — per-variable reference levels

A dict maps each categorical variable name to its chosen reference level. Variables not mentioned in the dict fall back to 'FIRST' (patsy default). The reference level value must be supplied as a string exactly matching a value in that column. 

# Set 'management' as reference for job_C, 'married' for marital_C
result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C', 'marital_C'],
    ref        = {'job_C': 'management', 'marital_C': 'married'}
)
Validation: When using the dict form, the library validates that each key is a column in data and each value is an actual level in that column. A ValueError is raised on mismatch — check column names and values exactly.

Optional Statistics

Two additional statistics blocks are off by default to match SAS defaults. Enable either or both independently.

rsquare — R-Square metrics

SAS equivalent: MODEL outcome = predictors / RSQUARE;

When rsquare=True, two pseudo R-Square values are printed in the console summary and included in the HTML output:

  • R-Square — computed from the full and null log-likelihoods and n. Analogous to Cox & Snell R². Always between 0 and a value less than 1.
  • Max-rescaled R-Square — R-Square rescaled so that its theoretical maximum equals 1. Analogous to Nagelkerke R². Directly comparable across models with different sample sizes.

Both values are printed to the number of decimals specified. Neither appears in .dataset — they are summary statistics, not per-parameter rows. 

result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C'],
    rsquare    = True
)

lackfit — Hosmer-Lemeshow goodness-of-fit test

SAS equivalent: MODEL outcome = predictors / LACKFIT;

When lackfit=True, the Hosmer-Lemeshow test is computed and printed. This test assesses whether the model fits the data well by comparing observed and expected event counts across groups of observations sorted by predicted probability.

Two blocks are printed:

  • Partition table — rows for each decile group showing: Group number, Total observations, Observed event count, Expected event count, Observed non-event count, Expected non-event count. The grouping algorithm follows the exact SAS SECT046 method (block-aware decile splitting with a minimum group size of n/20).
  • Test summary — Chi-Square statistic, degrees of freedom, and p-value. A large p-value (e.g. > 0.05) suggests the model fits the data adequately. A small p-value suggests lack of fit. 
result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C', 'balance'],
    lackfit    = True
)

Plots

All plots are generated using Plotly and are off by default. When enabled, plots are embedded in the HTML output file and are also accessible as properties on the result object for further customisation. Use plot_options for global size/title overrides at call time, or the helper functions for per-plot customisation after the call.

forest_plot — Forest Plot of Odds Ratios

Enable with forest_plot=True. Access via result.forest_plot.

Displays each non-intercept parameter as a point (the odds ratio) with horizontal error bars (Wald CI). A vertical reference line is drawn at OR = 1.0. Points to the right of 1 indicate increased odds of the event; points to the left indicate decreased odds. Markers and CI lines are steel-blue by default.

Default dimensions: 800 × 500 px.

roc_plot — ROC Curve

Enable with roc_plot=True. Access via result.roc_plot.

Plots sensitivity (true positive rate) against 1-specificity (false positive rate) across 200 threshold values from 0 to 1. The AUC (area under the curve) is displayed in the legend. A diagonal dashed reference line (random classifier) is included. AUC closer to 1 indicates better discrimination.

Default dimensions: 700 × 600 px.

influence — Influence Diagnostic Plots (two panels)

Enable with influence=True. Access via result.influence_plot → returns (panel1, panel2).

Two 2×2 subplot panels, each diagnostic plotted against case (observation) number:

  • Panel 1: Pearson Residual, Deviance Residual, Leverage, CI Displacement C
  • Panel 2: CI Displacement Cbar, Chi-Square Deletion Difference, Deviance Deletion Difference

Points with notably large values on any diagnostic may indicate influential observations that have an outsized effect on the model estimates.

Default dimensions: 1000 × 700 px per panel.

effect_plot — Predicted Probability Curve

Enable with effect_plot=True. Access via result.effect_plot.

Plots the model's predicted probability of the event against the first continuous predictor (the predictor with the most unique values). If a categorical predictor is present, separate lines are drawn for each of its levels. All other continuous predictors are fixed at their mean; other categorical predictors at their mode. A subtitle shows the fixed values used.

Default dimensions: 900 × 550 px.

plot_options dict

Passed at call time, applies to all plots generated in that call: 

result = C2Logistic(
    data         = df,
    outcome      = 'y',
    predictors   = ['age', 'job_C'],
    forest_plot  = True,
    roc_plot     = True,
    plot_options = {
        'width'  : 1000,
        'height' : 600,
        'title'  : 'Model 1 — Bank Marketing'
    }
)

For per-plot control use the helper functions after the call.

Plot Helper Functions

Four standalone functions allow post-hoc customisation of plot figures returned by the result object. Each accepts a Plotly figure from the corresponding result property, applies the requested changes, and returns a new figure. The original result object is not modified.

C2ForestPlot

C2ForestPlot(plot, title=None, width=None, height=None, color=None, marker_size=None)
plot Plotly Figure required

Pass result.forest_plot directly.

title str None

Override the plot title.

width int None

Figure width in pixels.

height int None

Figure height in pixels.

color str None

Colour for markers and CI error bars. Any valid CSS/Plotly colour string, e.g. 'darkblue', '#c0392b'.

marker_size int None

Size of the OR point markers in pixels.

    title       = 'Odds Ratios — Model 1',

Output & Export

HTML output

The default output='html' saves a self-contained HTML report styled to resemble SAS PROC LOGISTIC output (monospace font, tabular layout). The report contains all result tables (model info, observations, response profile, classification variable details, fit statistics, global tests, Type III tests, association statistics, parameter estimates, odds ratios) plus any enabled plots embedded inline as interactive Plotly charts. Plotly JS is loaded from CDN only when plots are present.

CSV / Excel

output='csv' and output='excel' save the .dataset DataFrame directly to a flat file. These formats contain only the per-parameter numeric results — no formatted tables, no plots. Useful for downstream analysis in other tools.

.dataset property

Available on any result object regardless of output setting. Returns a pandas DataFrame with one row per parameter per BY-group. Column reference:

ColumnDescription
labelBY-group identifier (empty string if no BY variable)
parameterParameter name (cleaned from patsy C() notation)
log_orLog odds ratio (parameter estimate)
seStandard error of the log odds ratio
wald_chisqWald chi-square statistic = (log_or / se)²
p_valueTwo-sided p-value from chi-square(1) distribution
log_or_lower_95 / log_or_upper_95CI bounds on log scale (suffix reflects ci= setting)
odds_ratioexp(log_or)
or_lower_95 / or_upper_95CI bounds on odds ratio scale
n_obsNumber of observations used in this fit
convergedBoolean — did Fisher scoring converge?
iterationsNumber of iterations taken
separation'none', 'quasi', or 'complete'
warning_issuedBoolean — was a separation warning raised?
df_results = result.dataset
df_results.to_csv('my_results.csv', index=False)

# Filter to significant parameters only
sig = df_results[df_results['p_value'] < 0.05]
