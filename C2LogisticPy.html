C2LogisticPy

Python binary logistic regression library

C2ProcLogistic provides two classes — C2Logistic and C2LogisticE — for fitting binary logistic regression models. Both classes accept identical arguments and produce identical output structures. The only difference is the coding method applied to categorical predictors.

On construction, the model fits immediately, prints a console summary, builds any requested plots, and saves the output file — all in a single call.

Coding Methods

When a predictor column is non-numeric (categorical), it must be converted into numeric columns before model fitting. The two classes differ only in how this conversion is done. Numeric (continuous) predictors are unaffected by the coding method in either class.

Reference coding — C2Logistic

For a categorical variable with levels A, B, C where C is the reference (default: last sorted), two binary columns are created: one for A (1 if A, else 0) and one for B (1 if B, else 0). The reference level C has no column — it is absorbed into the intercept.

Each coefficient is the log-odds of the event for that level relative to the reference level, holding all other predictors constant. The reference level does not appear in the parameter table.

Effect coding — C2LogisticE

Same column structure as reference coding, except the reference level receives −1 in every dummy column instead of 0. All other levels still receive 0 or 1 as normal.

Each coefficient represents the deviation of that level's log-odds from the unweighted grand mean log-odds across all levels. Use this when you want to interpret effects relative to an overall average rather than relative to a specific reference category.

C2Logistic

class
C2Logistic(data, outcome, predictors, event=None, ref='LAST', by=None, maxiter=25, ci=0.95, rsquare=False, lackfit=False, decimals=4, output='html', filepath=None, forest_plot=False, roc_plot=False, influence=False, effect_plot=False, plot_options=None)

Fits a binary logistic regression model using reference (dummy) coding for categorical predictors. Model fitting uses Fisher scoring (iteratively reweighted least squares) with convergence criterion gradient < 1e-8.

Parameters

data pd.DataFrame required

Input dataset. All outcome and predictor columns must be present. Rows with missing values in the outcome or any predictor are dropped before fitting.

outcome str required

Name of the binary response variable column. Accepts numeric 0/1 or a two-level string column (e.g. 'yes'/'no'). For numeric 0/1 columns the model fits as-is, modelling P(y=1). For non-numeric columns the higher alphabetically-sorted level is the event by default — override with event.

predictors list of str required

List of predictor column names, e.g. ['age', 'job_C', 'balance']. Numeric columns enter the model as continuous. Non-numeric columns are automatically encoded using the class coding method. Column dtype determines treatment, not the name.

event str default: None

Which value of outcome is the event (modelled as P=1). Only relevant when the outcome column is non-numeric. Pass the exact value as a string, e.g. event='yes'. If None, the higher alphabetically-sorted level is used. Raises ValueError if the value is not found in the column.

ref str or dict default: 'LAST'

Reference level for categorical predictors. Three forms:

  • 'LAST' — last sorted level is the reference. This is the default.
  • 'FIRST' — first sorted level is the reference.
  • {'varname': 'level'} — reference level specified per variable. Variables absent from the dict fall back to 'FIRST'.

No effect on numeric predictors. See The ref Argument for examples.

by str default: None

Grouping column name. When supplied, the model is fitted separately for each unique value of this column. All group results are included in a single output file. The .dataset property includes a label column identifying each group, e.g. "education = primary".

maxiter int default: 25

Maximum Fisher scoring iterations. If the model does not converge within this limit, a warning is issued and results are reported at the final iteration.

ci float default: 0.95

Confidence interval level as a proportion. Default 0.95 gives 95% Wald intervals for log-odds and odds ratios. Accepts any value strictly between 0 and 1. Raises ValueError otherwise.

rsquare bool default: False

When True, prints R-Square and Max-rescaled R-Square in the console summary and HTML output. Both are computed from the full and null log-likelihoods. See Optional Statistics — rsquare.

lackfit bool default: False

When True, prints the Hosmer-Lemeshow goodness-of-fit test — partition table plus chi-square statistic with p-value. See Optional Statistics — lackfit.

decimals int default: 4

Decimal places in all printed tables — console and HTML. Applies to estimates, standard errors, odds ratios, confidence intervals, and p-values. The .dataset DataFrame always stores 6 decimal places regardless.

output str default: 'html'

Format of the saved output file:

  • 'html' — styled report with all tables and embedded plots
  • 'csv' — flat CSV of the .dataset DataFrame
  • 'excel' — Excel .xlsx of the .dataset DataFrame

Raises ValueError for any other value.

filepath str default: None

Full path including filename for the output file. If None, saved in the current working directory as output.html, output.csv, or output.xlsx. Directory path may be included, e.g. 'results/run1.html'.

forest_plot bool default: False

When True, generates a Forest Plot of odds ratios with Wald confidence intervals for all non-intercept parameters. Embedded in HTML output and accessible as result.forest_plot.

roc_plot bool default: False

When True, generates an ROC curve across 200 threshold values with AUC in the legend. Accessible as result.roc_plot.

influence bool default: False

When True, generates two 2×2 panels of influence diagnostics. Accessible as result.influence_plot which returns a tuple (panel1, panel2). See Influence Plots.

effect_plot bool default: False

When True, generates a predicted probability curve against the first continuous predictor, with separate lines per level of the first categorical predictor if present. Other continuous predictors held at their mean; categoricals at their mode. Accessible as result.effect_plot.

plot_options dict default: None

Plotly display overrides applied to all plots in the call. Accepted keys: 'width', 'height', 'title'. For per-plot control use the helper functions after the call.

Attributes / Returns

.dataset pd.DataFrame

Results as a flat DataFrame. One row per parameter per BY-group. Columns: label, parameter, log_or, se, wald_chisq, p_value, CI bounds for log-OR and OR (e.g. or_lower_95, or_upper_95), odds_ratio, n_obs, converged, iterations, separation, warning_issued.

.forest_plot Plotly Figure

Available only when forest_plot=True. Raises RuntimeError if accessed without enabling.

.roc_plot Plotly Figure

Available only when roc_plot=True. Raises RuntimeError if accessed without enabling.

.influence_plot tuple — (panel1, panel2)

Available only when influence=True. Returns a tuple of two Plotly figures. Raises RuntimeError if accessed without enabling.

.effect_plot Plotly Figure

Available only when effect_plot=True. Raises RuntimeError if accessed without enabling.

C2LogisticE

class
Identical interface to C2Logistic. Every argument name, type, and default is the same. The only difference is categorical predictors are encoded with effect coding (reference level = −1) instead of reference coding (reference level = 0).
C2LogisticE(data, outcome, predictors, event=None, ref='LAST', by=None, maxiter=25, ci=0.95, rsquare=False, lackfit=False, decimals=4, output='html', filepath=None, forest_plot=False, roc_plot=False, influence=False, effect_plot=False, plot_options=None)

Parameters

All parameters identical to C2Logistic. The ref argument still controls which level is the reference — in effect coding that level receives −1 across all dummy columns instead of being omitted. The console header prints [PARAM=EFFECT] to distinguish output.

Examples

from C2ProcLogistic import C2LogisticE

result = C2LogisticE(
    data        = df,
    outcome     = 'purchased',
    event       = 'yes',
    predictors  = ['age', 'balance_T', 'job_C'],
    ref         = 'LAST',
    rsquare     = True,
    lackfit     = True,
    forest_plot = True,
    roc_plot    = True,
)

df_out = result.dataset

The ref Argument

Controls the reference level for categorical (non-numeric) predictors. Applies in both C2Logistic and C2LogisticE. No effect on numeric columns.

'LAST' — default

Last alphabetically-sorted level becomes the reference for each categorical predictor. For levels ['admin', 'blue-collar', 'student'] the reference is 'student'. Estimates appear for admin and blue-collar only. 

result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C'],
    ref        = 'LAST'   # default — can be omitted
)

'FIRST'

First alphabetically-sorted level is the reference. For ['admin', 'blue-collar', 'student'] the reference is 'admin'. 

result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C'],
    ref        = 'FIRST'
)

dict — per-variable reference levels

Specify the reference level for each categorical variable independently. Variables not in the dict fall back to 'FIRST'. The value must exactly match a level in that column. 

result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C', 'marital_C'],
    ref        = {'job_C': 'management', 'marital_C': 'married'}
)
Both the key (column name) and the value (level) are validated against the data. A ValueError is raised if either does not match exactly.

Optional Statistics

rsquare

When rsquare=True, two pseudo R-Square values are added to the console summary and HTML output:

  • R-Square — Cox & Snell pseudo R². Always less than 1.
  • Max-rescaled R-Square — Nagelkerke R². Rescaled so maximum = 1. Comparable across models with different sample sizes.

Neither value appears in .dataset — they are model-level summaries, not per-parameter rows.

result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C'],
    rsquare    = True
)

lackfit — Hosmer-Lemeshow test

When lackfit=True, the Hosmer-Lemeshow goodness-of-fit test is computed and printed. Compares observed and expected event counts across decile groups sorted by predicted probability. Two blocks are printed:

  • Partition table — per group: total, observed event count, expected event count, observed non-event count, expected non-event count.
  • Test summary — chi-square statistic, degrees of freedom, p-value. A large p-value indicates adequate fit; a small p-value indicates lack of fit.
result = C2Logistic(
    data       = df,
    outcome    = 'y',
    predictors = ['age', 'job_C', 'balance'],
    lackfit    = True
)

Plots

All plots use Plotly and are off by default. When enabled, plots are embedded in the HTML output and accessible as result properties for further customisation.

forest_plot — Forest Plot of Odds Ratios

Enable: forest_plot=True  ·  Access: result.forest_plot

Each non-intercept parameter shown as a point (odds ratio) with horizontal Wald CI bars. Reference line at OR = 1.0. Points right of 1 indicate increased odds; left indicate decreased odds. Default dimensions: 800 × 500 px.

roc_plot — ROC Curve

Enable: roc_plot=True  ·  Access: result.roc_plot

Sensitivity vs 1-specificity across 200 thresholds. AUC shown in legend. Diagonal dashed reference line included. Default dimensions: 700 × 600 px.

influence — Influence Diagnostic Plots

Enable: influence=True  ·  Access: result.influence_plot → (panel1, panel2)

Two 2×2 panels, each diagnostic plotted against case number:

  • Panel 1: Pearson Residual, Deviance Residual, Leverage, CI Displacement C
  • Panel 2: CI Displacement Cbar, Chi-Square Deletion Difference, Deviance Deletion Difference

Default dimensions: 1000 × 700 px per panel.

effect_plot — Predicted Probability Curve

Enable: effect_plot=True  ·  Access: result.effect_plot

Predicted probability of the event against the first continuous predictor. Separate lines per level of the first categorical predictor if present. Other continuous predictors fixed at mean; categoricals at mode. Default dimensions: 900 × 550 px.

plot_options dict

Applied to all plots in the call. Keys: 'width', 'height', 'title'.

result = C2Logistic(
    data         = df,
    outcome      = 'y',
    predictors   = ['age', 'job_C'],
    forest_plot  = True,
    roc_plot     = True,
    plot_options = {'width': 1000, 'height': 600}
)

Output & Export

HTML output

The default output='html' saves a self-contained styled HTML report containing all result tables — model info, observations, response profile, classification variable details, fit statistics, global tests, Type III tests, association statistics, parameter estimates, odds ratios — plus any enabled plots embedded as interactive Plotly charts. Plotly JS is loaded from CDN only when plots are present.

CSV / Excel

output='csv' and output='excel' write the .dataset DataFrame to a flat file. Per-parameter numeric results only — no formatted tables, no plots.

.dataset property

One row per parameter per BY-group. Column reference:

ColumnDescription
labelBY-group identifier. Empty string if no BY variable.
parameterParameter name, cleaned from patsy C() notation.
log_orLog odds ratio (parameter estimate).
seStandard error of the log odds ratio.
wald_chisq(log_or / se)²
p_valueTwo-sided p-value from chi-square(1).
log_or_lower_95 / log_or_upper_95CI bounds on log scale. Suffix reflects the ci= setting.
odds_ratioexp(log_or)
or_lower_95 / or_upper_95CI bounds on odds ratio scale.
n_obsObservations used in this fit.
convergedBoolean — did Fisher scoring converge?
iterationsNumber of iterations taken.
separation'none', 'quasi', or 'complete'.
warning_issuedBoolean — was a separation warning raised?
df_results = result.dataset
df_results.to_csv('my_results.csv', index=False)

sig = df_results[df_results['p_value'] < 0.05]

C2LogisticE — effect coding

from C2ProcLogistic import C2Logistic, C2LogisticE

# Reference coding — coefficients vs reference level
res_ref = C2Logistic(data=df, outcome='y', predictors=['age', 'job_C'], ref='LAST')

# Effect coding — coefficients vs grand mean
res_eff = C2LogisticE(data=df, outcome='y', predictors=['age', 'job_C'], ref='LAST')

print(res_ref.dataset[['parameter', 'log_or', 'odds_ratio']])
print(res_eff.dataset[['parameter', 'log_or', 'odds_ratio']])
